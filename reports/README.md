# CryptoPrism Database Reports

Generated reports from database analysis, testing, and optimization tools.

## 📁 Directory Structure

### 📊 Analysis Reports (`analysis_reports/`)
Comprehensive markdown reports from various database analysis tools.

**Schema Analysis Reports:**
- Database structure analysis
- Table relationship documentation
- Column analysis and recommendations
- Schema validation results

**Performance Analysis Reports:**
- Query performance baselines
- Optimization recommendations
- Index analysis results
- Database health assessments

**Validation Reports:**
- Data integrity check results
- Quality assurance findings
- Constraint validation outcomes
- Business rule compliance

### 📈 Test Results (`test_results/`)
JSON formatted test results and performance metrics.

**Performance Test Results:**
- Query execution timelines
- Database benchmark data
- Performance regression analysis
- Load testing outcomes

**Validation Test Results:**
- Data quality test results
- Schema validation outcomes
- Integrity check results
- Compliance test data

## 🔍 Report Types

### Generated by Tools

- **Schema Analysis**: `tools/schema_analysis/` → `analysis_reports/`
- **Performance Testing**: `tools/performance/` → `test_results/`
- **Validation Suite**: `tools/validation/` → Both directories
- **Primary Key Analysis**: `tools/primary_keys/` → `analysis_reports/`
- **Indexing Analysis**: `tools/indexing/` → `analysis_reports/`

### Report Naming Convention

```
{tool_name}_{report_type}_{timestamp}.{extension}

Examples:
- comprehensive_database_report_20250907.md
- performance_test_results_20250908_121941.json
- dbcp_validation_report_20250907.md
- live_database_analysis_report.md
```
